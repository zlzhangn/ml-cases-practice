# 路线图（Roadmap）

## 总体策略

**小步快跑，一次只做一件事**。将 7 个案例 + 基础设施拆分为 8 个独立阶段，每个阶段只聚焦一个目标，降低认知负担，快速获得正反馈。

## 时间线总览

```
周次:   1        2        3        4        5        6        7        8
阶段:  P0       P1       P2       P3       P4       P5       P6       P7
内容: 骨架   客户流失  销售预测  量化因子  异常检测  NLP分类  因果推断  回测框架
       │        │        │        │        │        │        │        │
       ▼        ▼        ▼        ▼        ▼        ▼        ▼        ▼
      基建     分类     时序     金融     风控     文本     决策     工程
```

### Phase 0：搭建骨架（第 1 周）

**唯一目标**：让后续 7 个案例能"开箱即用"。

**任务清单**：
- [x] `pyproject.toml` + `uv.lock` — 依赖锁定

**退出标准**：新建一个案例目录，复制模板后 5 分钟内能开始写代码。

---

### Phase 1：客户流失预测（第 2 周）

**唯一目标**：跑通第一个完整案例，建立信心。

**任务清单**：
- [ ] 从 HuggingFace 加载 `aai510-group1/telco-customer-churn`

**退出标准**：AUC > 0.80，能解释 Top 5 关键特征的业务含义。

---

### Phase 2：销售/需求预测（第 3 周）

**唯一目标**：在案例 1 基础上，增加时序维度。

**任务清单**：
- [ ] 从 HuggingFace 加载 `t4tiana/store-sales-time-series-forecasting`
- [ ] 时序 EDA（趋势、季节性、平稳性）
- [ ] 时序特征工程（滞后、滑动窗口、年月日特征）

**退出标准**：MAPE < 20%，理解为什么时序不能用随机划分。

---

### Phase 3：量化因子与择时信号（第 4 周）

**唯一目标**：掌握金融数据的因子思维和评估方法。

**任务清单**：

- [ ] 理解季度因子数据的结构

**退出标准**：至少 1 个因子 IC > 0.03，分层收益单调。

### Phase 4：异常检测与风控（第 5 周）

**唯一目标**：处理极端不平衡，掌握混合建模策略。

**任务清单**：

- [ ] 无监督模型（Isolation Forest、LOF）建立基线

**退出标准**：有监督模型 AUC > 0.90，Recall > 0.85。

### Phase 5：NLP 文本分类（第 6 周）

### Phase 6：因果推断与策略评估（第 7 周）

**唯一目标**：从"预测"升级到"决策"，理解因果 vs 相关的区别。

## 实施原则

1. **一次一个阶段**：不要同时开多个案例，完成当前再进入下一个
2. **前置不完成，后续不启动**：P7 必须等 P2 和 P3 完成
3. **验收不过，不许过关**：每个阶段有明确的退出标准，达不到就停在这个阶段优化
4. **允许提前退出**：如果某个阶段的任务提前完成，可以立即进入下一阶段，不必等满一周
