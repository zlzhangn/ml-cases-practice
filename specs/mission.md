# 项目使命（Mission）

## 项目名称

ml-cases-practice：通过真实案例掌握机器学习实战能力

## 背景与动机

在工作和交易场景中，机器学习（ML）已经成为解决实际问题的核心工具。然而，真正掌握 ML 的能力不仅需要理解算法原理，更需要在真实数据和业务场景中反复实践。本项目通过 7 个递进式案例，覆盖分类、回归、时间序列、异常检测、NLP、因果推断、量化回测等核心领域，帮助学习者建立端到端的 ML 解决能力。

## 核心目标

1. **建立实战能力**：每个案例走完完整的 `数据获取 → 数据清洗 → EDA → 特征工程 → 建模 → 评估 → 优化` 链路。
2. **覆盖核心场景**：工作和交易场景中高频出现的 ML 问题类型。
3. **使用真实数据**：所有案例基于 HuggingFace 和 ModelScope 上的真实业务数据集。
4. **养成工程习惯**：引入 MLflow 实验追踪、配置驱动开发、模块化代码等工程化实践。

## 目标人群

- 有一定 Python 基础，希望系统提升 ML 实战能力的学习者
- 需要在工作或交易场景中应用 ML 的从业者
- 希望通过案例驱动方式快速建立 ML 直觉的开发者

## 范围限定（非目标）

以下**不在**本项目范围内：

- 深度学习和计算机视觉（CNN、RNN、Transformer 微调等）
- 强化学习（交易执行优化除外，但不做强化学习模型）
- 推荐系统（单列模型、排序学习等）
- 大规模分布式训练
- 完整的 MLOps 生产流水线（仅做实验追踪，不做 CI/CD、模型服务化）

## 开发原则

1. **快速跑通优先**：每个案例先走完完整链路，不求最优解。7 个案例全部完成后，再回头针对性优化。
2. **中文优先**：所有文档、注释、报告均使用中文，降低阅读门槛。
3. **规范开发**：统一目录结构、配置管理、代码风格、实验记录方式。
4. **数据驱动**：所有结论必须有数据和图表支撑，禁止主观臆断。
5. **可复现**：每个案例提供完整的 `config.yaml` 和依赖锁定，确保环境一致。

## 成功标准

完成 7 个案例后，学习者应能：

- 独立处理一个陌生的表格/文本数据集的端到端建模任务
- 判断何时使用分类、回归、时序、无监督、因果推断等不同类型的 ML 方法
- 解释模型结果（SHAP、特征重要性、因子 IC 等），并用业务语言呈现结论
- 识别和防范过拟合、数据泄漏、样本不平衡等常见问题
- 搭建一个基础的量化策略回测框架并评估其表现

## 数据来源

所有案例数据均来自公开平台：

- HuggingFace Datasets（主要来源，可以通过HF-Mirror镜像站获取）
- ModelScope 数据集（中文场景补充）
- Kaggle 公开数据集（通过 HuggingFace 镜像获取）
